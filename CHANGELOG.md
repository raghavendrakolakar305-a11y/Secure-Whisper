# Changelog

## 1.0.0 - 2026-11-21

### Added

- React 18 + TypeScript + Vite frontend.
- Express + Node.js backend.
- MongoDB/Mongoose persistence.
- JWT authentication and bcrypt password hashing.
- WebSocket real-time messaging and presence.
- Friend requests and friend management.
- AES-256-GCM encrypted message storage.
- Message reactions, replies, seen/read state, and file metadata.
- Render deployment configuration.
- Repository documentation, CI, dependency automation, and release packaging workflow.

### Security

- Secrets remain environment-based and are excluded from source control.
- Documentation clearly distinguishes server-side encrypted messaging from true E2EE.
